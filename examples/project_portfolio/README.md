# Portfolio project validation

This directory contains the deterministic 48-row fixtures and source-backed BI artifacts generated by `scripts/build_project_portfolio.py`.

Every project is rendered with its catalogued dashboard template and validated for a collision-free layout, at least two KPIs, two charts, one table, HTML/PDF/XLSX generation, a Power BI PBIP project bundle, and Tableau TWBX/TWB workbooks. Power BI projects use the integrated `powerbi_executive_sales`, `powerbi_ecommerce_conversion`, or `powerbi_kpi_slicer` reference templates. Extract a `report.pbip.zip` before opening the `.pbip` shortcut in Power BI Desktop (PBIP preview), or open `report.twbx` in Tableau Desktop/Reader.

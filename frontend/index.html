    Data Quality Analysis

    Comprehensive assessment of missing values, outliers, and schema anomalies.

    Diagnose the dataset first, then build a safe improvement plan with preview and approval.

    The proposed recipe will never change the dataset until you approve Apply.

    GOVERNED BI HANDOFF

    BI-ready data

    Turn the selected dataset into a clean, modeled handoff for Power BI, Tableau, or the built-in report generator. Preview first; Apply creates a new immutable version.

    Profile the selected dataset to see recommended BI transformations, fact grain, dimensions, measures, and blockers.

    Statistical Summary

    Descriptive statistics and aggregations for all numeric columns.

    Click "Run Analysis" to generate the statistical summary.

    SQL Lab

    Run bounded read-only SQL against the current dataset table. CTEs, subqueries, windows, CASE, dates, ranking, and running totals are supported.

    Use table name dataset, then run a read-only query.

    Exploratory Data Analysis (EDA)

    Advanced correlations and distributional insights.

    Click "Run Analysis" to generate the EDA report.

    Forecast Studio

    Readiness, diagnostics, backtesting, model selection, intervals, and planning from one governed workflow.

    Choose a date and value column, then check readiness or generate a forecast.

    Machine Learning Studio

    Leakage-safe preparation, bounded AutoML, tuning, explainability, uncertainty, and model registration.

    Select a target for supervised learning, or run clustering without one.
